To-Do-App

Overview
This is my submission for the To Do app as part of The Odin Project. This app uses a users local storage to store tasks and projects. Users can then create, read, update and delete these tasks and projects and come back to them at a later point.

Technologies Used
Javascript, HTML, CSS, Webpack, JSON

Lessons Learned
This project has been a big learning curve for me. It's my first CRUD app, my first app with any kind of persistence and my first project using modules in a serious way.

In the future I want to focus more on SOLID and DRY principles. Some of my larger modules should really have been seperated out and I could have used some helper functions to speed up and simplify creating DOM elements.

Overall I'm really happy with the lessons learned in this project, it feels like a major jump in difficulty and complexity when compared to previous project in the Odin Project
